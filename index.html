Frequently asked questions

Know what is live—and what comes next.

The dashboard displays live DayZ server information plus each signed-in member's own survivor profile and economy summary. Server-changing controls remain locked for later stages.

Is the dashboard using live server data?

Yes. Server status, player count, capacity, map, platform and update time are public. Signed-in members can also load their own verified profile and economy summary.

Can I sign in with Discord?

Yes. Discord identifies your account, then Railway checks your current membership and roles in the World War Z server. Only the basic identify permission is requested.

Will members and Admins see the same tools?

No. Members see personal self-service areas. Admin and Owner navigation stays completely hidden unless Railway verifies the required Discord access.

Does the website store bot tokens?

No. Discord bot tokens, Nitrado credentials and other secrets must never be placed in this public GitHub Pages website.
