Privacy & security

Clear boundaries for community data.

This page explains the live public server connection and the privacy rules planned for future account features. Last updated 3 August 2026.

Current websiteFuture sign-inPermissionsSecurityData handlingContact
Current status: the dashboard requests read-only public server information from the bot on Railway. Discord accounts, private player records and protected controls are not connected.

Current public website

The website is publicly hosted through GitHub Pages. It does not include analytics, advertising trackers or account cookies. The dashboard requests only public server status, player totals, capacity, map, platform and update time from the World War Z Bot API.

Other dashboard records remain fictional demonstrations. Links to Discord, GitHub or another service take you to that service, where its own privacy terms apply.

Future Discord sign-in

When secure sign-in is enabled, the dashboard is expected to use Discord authentication to identify your Discord account and confirm your membership and roles in the World War Z community.

Expected account information

  • Your Discord user identifier and display information.
  • Your membership and assigned roles in the World War Z Discord server.
  • Your existing bot profile, such as a linked PlayStation ID, when one already exists.

The final authorisation screen and data handling will be reviewed before sign-in is activated.

Access permissions

Dashboard features will be assigned by role. Visitors will receive public information, members will receive their own account features, staff will receive approved moderation tools, and owner-only server controls will remain restricted.

A Discord role check should occur before protected information is returned or a protected action is accepted.

Security boundaries

  • Discord bot tokens, Discord client secrets and Nitrado API credentials remain on the Railway service.
  • The public API does not return online player names, credentials or private bot records.
  • Secrets must never be committed to the public website repository or exposed to browser JavaScript.
  • Administrative actions require future authentication, permission checks, confirmation and an audit record.
  • The public dashboard cannot restart the server, edit balances, expose player records or change configuration files.

Data handling and retention

The current public status connection does not create a dashboard account or store personal information in the browser. Before account features launch, retention rules will be defined for login sessions, audit logs, tickets and moderation records. Community records already managed by the Discord bot remain subject to the bot's own administration processes.

Questions or requests

For questions about the World War Z community, your bot profile or future dashboard information, use the community's established Discord support ticket process.
