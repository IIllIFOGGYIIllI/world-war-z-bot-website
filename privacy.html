Privacy & security

Clear boundaries for community data.

This page explains the current public preview and the privacy rules planned for the future connected dashboard. Last updated 3 August 2026.

Current websiteFuture sign-inPermissionsSecurityData handlingContact
Current status: the dashboard is a demonstration interface. It does not connect to Discord accounts, the bot, Nitrado or the player database.

Current public website

The website is publicly hosted through GitHub Pages. Its own code does not include analytics, advertising trackers or account cookies. The dashboard uses fictional demonstration data and does not submit information to the World War Z Bot.

Links to Discord, GitHub or another service take you to that service, where its own privacy terms apply.

Future Discord sign-in

When secure sign-in is enabled, the dashboard is expected to use Discord authentication to identify your Discord account and confirm your membership and roles in the World War Z community.

Expected account information

  • Your Discord user identifier and display information.
  • Your membership and assigned roles in the World War Z Discord server.
  • Your existing bot profile, such as a linked PlayStation ID, when one already exists.

The final authorisation screen and data handling will be reviewed before sign-in is activated.

Access permissions

Dashboard features will be assigned by role. Visitors will receive public information, members will receive their own account features, staff will receive approved moderation tools, and owner-only server controls will remain restricted.

A Discord role check should occur before protected information is returned or a protected action is accepted.

Security boundaries

  • Discord bot tokens, Discord client secrets and Nitrado API credentials must remain on the secure Railway service.
  • Secrets must never be committed to the public website repository or exposed to browser JavaScript.
  • Administrative actions should require authentication, permission checks, confirmation and an audit record.
  • The public preview cannot restart the server, edit balances, expose player records or change configuration files.

Data handling and retention

The connected dashboard has not launched, so no dashboard retention period is currently in effect. Before launch, retention rules should be defined for login sessions, audit logs, tickets and moderation records. Community records already managed by the Discord bot remain subject to the bot's own administration processes.

Questions or requests

For questions about the World War Z community, your bot profile or future dashboard information, use the community's established Discord support ticket process.
