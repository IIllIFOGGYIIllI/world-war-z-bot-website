Website changelog

Every update, clearly recorded.

Release notes for the public World War Z Bot website and the dashboard experience.

4 August 2026

Version 1.13.0

Command Centre UI overhaul

Redesigned

  • Rebuilt the dashboard atmosphere with a cinematic Chernarus-inspired background, stronger information hierarchy and modern glass-and-metal control panels.
  • Replaced the temporary text mark with a refined World War Z logo across the dashboard, public website, privacy page, changelog and 404 page.
  • Redesigned navigation, status cards, view headers, protected action controls, dialogs, mobile layouts and public landing-page sections.
  • Added local favicon, application icon and responsive background assets without introducing third-party requests.

Preserved

  • All Stage 7B2 authentication, player administration, map, profile, economy and server-control data attributes and workflows remain intact.
  • The redesign changes presentation only and does not expose new public information or credentials.

4 August 2026

Version 1.12.1

Player action confirmation hotfix

Fixed

  • Action-level permission rejections no longer clear valid Admin access or redirect to Overview.
  • The real rejection reason remains visible inside the player-action dialog.
  • Expired sessions and genuine loss of Admin access still use the existing secure sign-out or downgrade flow.

Improved

  • The selected PlayStation ID is displayed in the dialog instead of requiring it to be typed for every action.
  • Admins now enter the reason and confirm with the action button.
  • Railway continues to validate the selected target and audit every accepted or rejected request.

4 August 2026

Version 1.12.0

Controlled player administration

Added

  • Private staff note creation and audited updates.
  • Active warning creation, reason editing and removal with linked cases.
  • Verified economy balance add, remove and set controls.
  • Discord kick, permanent ban and unban controls.
  • Real Nitrado DayZ ban-list add and remove controls.
  • Owner-only account unlinking after Railway creates a recovery snapshot.
  • Protected note, warning, DayZ ban and permanent action history panels.

Safety

  • Every action requires a reason and exact PlayStation ID confirmation.
  • Railway repeats Admin/Owner, target, Discord permission and role-hierarchy checks.
  • Self and Owner targets are protected; staff targets and unlinking require the Owner where applicable.
  • Simultaneous write requests are blocked and all accepted or rejected outcomes are audited.
  • No unsupported DayZ live-kick control is presented.

4 August 2026

Version 1.11.0

Secure read-only player administration

Added

  • Admin-only partial player search by PlayStation ID or Discord display name.
  • Minimum three-character searches, a 15-result cap and no database-wide listing.
  • Protected player identity, activity, playtime, session, PvP, warning-count and sanitized moderation views.
  • Loading, no-results, unlinked, unavailable and expired-session states.

Privacy and security

  • Railway repeats current Discord Admin or Owner authorization for every request.
  • Raw IDs, private notes, DayZ UIDs, positions, moderator identities, evidence and credentials are excluded.
  • All returned values are rendered as text, and Stage 7B1 provides no write controls.

4 August 2026

Version 1.10.0

Live server operations

Added

  • Public Railway uptime, Discord gateway health, sanitized Nitrado state and last successful update.
  • Protected recent Start, Stop and Restart history inside Admin Tools.
  • Loading, empty, unavailable, expired-session and refresh states.

Privacy and security

  • Railway rechecks current Admin or Owner access before returning history.
  • Members cannot see or receive the protected history.
  • Discord IDs, request IDs, raw upstream messages and credentials are excluded.
  • The next scheduled restart is shown only if a reliable value becomes available; it is never invented.

4 August 2026

Version 1.9.0

Complete protected server controls

Added

  • Connected protected Start and Stop controls beside Restart for verified Admins and the Owner.
  • One action-specific Yes/Cancel confirmation window with an optional audit reason.
  • Automatic status refreshes and clear accepted, cooldown, conflict and unavailable messages.

State and security

  • Start is enabled only while offline; Stop and Restart only while online.
  • All controls lock during transitions, requests and Railway cooldowns.
  • Railway rechecks Discord access and live server state, then records the action and outcome.

Version 1.8.1

Restart confirmation prompt

Changed

  • Replaced the typed RESTART requirement with clear Yes and Cancel choices.
  • Added a concise warning checklist before the Admin confirms the request.

Security

3 August 2026

Version 1.8.0

Secure Admin restart

Added

  • The verified Admin Restart server control now connects to Railway.
  • A confirmation dialog requires RESTART exactly and accepts an optional audit reason.
  • Clear accepted, cooldown, in-progress, expired-session and unavailable states.
  • Automatic server-status refresh after an accepted request.

Security

  • Railway rechecks current Discord Admin or Owner access for every request.
  • The browser never receives Nitrado, Discord bot or OAuth credentials.
  • Double submission is blocked and Railway shares its lock and cooldown with Discord controls.
  • Every submitted request is recorded in the database and configured Discord audit channel.
  • Stop and Start remain disabled.

WWZ Tactical Map

Version 1.4.0

Member profile & economy

Added

  • Live wallet, jackpot, heat, lifetime totals and personal ledger entries.
