Every Update, Clearly Recorded

Release notes for the public World War Z Bot website and the dashboard experience.

8 August 2026

Version 1.22.27

Unified Production Chernarus Map

Added And Changed

  • Replaced the retired custom/WebP Chernarus map with one shared Leaflet-based renderer backed by the corrected local JPG satellite pyramid.
  • Integrated the final grouped WRP-derived production road overlay across the main dashboard map, dashboard checkout, standalone Survivor Shop checkout and Saved Delivery Locations.
  • Added full-map Roads and Trails visibility controls while keeping embedded coordinate pickers compact.
  • Coordinate selection now uses one shared native DayZ X/Z conversion and writes values with one decimal place.
  • Retired the old overview image, WebP tile pyramid, tile report and legacy vector fallback.
  • Added a PowerShell production-asset installer and strict GitHub Pages map-asset validation.

Technical

  • Uses L.CRS.Simple, 15,360 m world dimensions, 240 Leaflet units and manual worldToLeaflet() → L.polyline() road rendering.
  • Uses non-interactive Canvas road layers, the approved 180% width multiplier and automatic road detail by zoom.
  • The final road layer expects 52,006 line parts across nine production groups and keeps the 15 unresolved records and 68 centerline diagnostics excluded.

Compatibility

  • Pairs with Bot v1.18.26.
  • No Railway API, authentication, role gating, database, shop/rental API contract or moderation behaviour changed.
  • Event Zone remains optional where already supported; no unnecessary event map was invented.
