Website changelog

Every update, clearly recorded.

Release notes for the public World War Z Bot website and the dashboard experience.

3 August 2026

Version 1.4.0

Member profile & economy

Added

  • Live personal PlayStation survivor profile for the signed-in member.
  • Playtime, sessions, activity, PvP, faction and event statistics.
  • Live wallet, jackpot, heat, lifetime totals and personal ledger entries.
  • Linked, unlinked, loading and unavailable account states.
  • A future interactive Chernarus POI-map foundation.

Access and security

  • Admin and Owner tabs remain hidden unless Railway verifies the required role.
  • The personal endpoint cannot select another member ID.
  • Warnings, Admin notes, raw Discord IDs and transaction counterparties are excluded.
  • The duplicate sign-in button no longer appears while connected.
  • User-facing access terminology now says Admin instead of Staff.

3 August 2026

Version 1.3.0

Secure Discord sign-in

Added

  • Real Discord OAuth sign-in through the World War Z Bot service on Railway.
  • Live Discord server membership and role verification.
  • Verified member, Admin and owner access labels.
  • Tab-based session restoration, secure sign-out and clear error states.
  • Updated homepage and privacy information.

Security

  • Discord requests only the basic identify permission.
  • The OAuth secret and Discord access token never enter the public website.
  • The one-time login ticket is removed from the address bar after exchange.
  • The session stays in the current tab and expires automatically.
  • Private records and server-changing controls remain unavailable.

3 August 2026

Version 1.2.0

Live server status

Added

  • Live read-only DayZ server status from the World War Z Bot API on Railway.
  • Live player count, server capacity, map, platform and API update time.
  • Automatic status refresh every 30 seconds and a manual refresh button.
  • Online, restarting, offline and temporarily unavailable display states.
  • The complete current catalogue of 30 top-level Discord commands.
  • Updated development roadmap, dashboard help and public privacy information.

Security

  • The public connection cannot perform server actions or access account information.
  • Online player names, Discord records and credentials are not requested or displayed.
  • Discord sign-in and protected operations remain locked for later backend stages.

3 August 2026

Version 1.1.0

Dashboard preview

Added

  • Interactive dashboard preview with responsive desktop and mobile layouts.
  • Overview, server, economy, player, ticket, Admin, configuration and settings views.
  • Searchable 25-command preview catalogue with category filters.
  • Discord sign-in preview that clearly explains the future connection.
  • Role-based access preview for visitors, members, Admins and the owner.
  • Fictional server, player, activity and backup demonstration data.
  • Frequently asked questions, privacy information and web changelog pages.
  • Dashboard links throughout the public website.

Security

  • All live controls remain disabled until the secure Railway API is available.
  • No Discord, Nitrado or member credentials are included.
  • Every demonstration record is clearly identified as preview data.
