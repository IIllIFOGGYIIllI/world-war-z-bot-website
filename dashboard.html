Questions

Dashboard help

Why are some buttons still locked?

The Railway API currently exposes safe, read-only public server status. Account data and server-changing actions remain locked until Discord authentication, permission checks, confirmations and audit logging are added.

Which displayed information is live?

The DayZ server status, player count, capacity, map, platform and API update time are live. Player examples, balances, tickets, activity and configuration history remain demonstration data.

What will Discord sign-in request?

The planned sign-in will identify your Discord account and check your World War Z server membership and roles. The exact permission screen will be reviewed before it is enabled.

What comes next?

The public Railway status connection is complete. The next dashboard backend stage will add secure Discord authentication and role-based access without exposing bot or Nitrado credentials.
